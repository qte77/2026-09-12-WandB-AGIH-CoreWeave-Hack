Jev Gate

A self-correcting agent loop that knows why it failed before it tries again.

GitHub repo Weave call tree (live example) W&B run

Jev Gate is a critique-refine agent loop that fixes real bugs in Elixir code — chosen over a generic Python/LeetCode demo since Elixir is rare enough in most models' training data that the loop has genuine work to do.

The loop

Draft attempt→ Execute for real→ TypeSafe diagnoses why→ Refine with diagnosis→ Re-execute

A cheap draft model attempts a fix. We actually execute it against real tests — pass/fail is execution-graded, never self-reported. On failure, TypeSafe's Jev model (System One's Choice primitive) diagnoses the specific failure class — logic_error, off_by_one, syntax_or_runtime_error, etc. — before a stronger model refines the fix using that diagnosis. Each retry is informed by a calibrated classification of what went wrong, not a blind re-ask.

Real results, not simulated

9 hand-authored Elixir tasks, each independently verified (buggy version fails, a correct fix passes) via real elixir execution before any LLM spend. The cheap 2.6B draft model alone solved 3 / 9 on the first try. Diagnosis-gated escalation closed the gap to 9 / 9 — 100%, verified via the W&B API, not the console log.

One example: the draft model wrote math:sqrt(n) — valid Erlang, invalid Elixir. TypeSafe correctly diagnosed it as a syntax_or_runtime_error; refine fixed it.

Honesty

Critique-refine is Self-Refine/Reflexion lineage, not a novel loop shape — we're not claiming otherwise. Not tested against a public benchmark. W&B Serverless Sandboxes was investigated for real (working SDK, working auth) but blocked on org entitlement, so execution runs in a local subprocess with a 10s timeout today, not isolated cloud compute.
